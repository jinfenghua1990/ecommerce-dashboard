# V1.6.1 — UI / 导航 / 动态布局

## 本版目标

在 V1.6.0 业务能力不变的前提下，收口全局 UI、业务路由与页面宽度，让首页、侧栏和各业务模块形成统一外壳，不再出现采购工作台重复嵌套、旧侧栏或大屏留白。

## 主要变更

- 经营总览升级为深色侧栏 + 浅色经营驾驶舱。
- 正式业务页面保持独立路由，不再被采购工作台统一重定向。
- `/purchase/workbench` 纳入统一全局侧栏，隐藏其历史 `WorkbenchSidebar`，避免双侧栏。
- 主内容区使用浏览器剩余宽度动态铺满；顶层历史 `max-width` 不再限制大屏。
- 宽表格限定在自己的横向滚动容器内，不让整个业务页被横向撑开。
- 新增 `npm run check:routes`：自动验证所有侧栏入口存在真实页面，并阻止正式业务页再次被加入旧采购重定向表。
- GitHub CI 前端阶段改为：导航路由检查 → TypeScript → Production static build。

## 不变内容

- 不修改真实业务数据。
- 不修改数据库结构。
- 不修改后端业务口径。
- 继续统一运行在 8000 端口。
- `release/v1.6.0` 保留为稳定回滚基线。
